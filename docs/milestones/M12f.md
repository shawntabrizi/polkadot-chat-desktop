# M12f — One spendable number in the meter header (spec 0008 v3) + M12e follow-ups

## Goal

The owner saw the header say "1 PAS" while `/balance` said 0.7, because the
bot charges in batches (M12c). Spec 0008 v3 adds `pending` to the balance
hint; the bot resends `botInfo` with the new `pending` in the same batch as
each metered reply (zero extra submissions); the header shows **one
number**, `balance − pending`, the same as `/balance`, with the on-chain
split only in a tooltip. The pca half (another agent, branch
`desktop/rfc-0003`) sends it and writes `docs/spec/vectors-0008c.md` first;
the desktop half decodes it. Plus three M12e follow-ups (review answers).

## Read first

- `docs/spec/0008-bot-info.md` (v2 balance hint; the new "v3: `pending`"
  section), `docs/spec/vectors-0008b.md` (v2 bytes), `docs/spec/efficiency.md`.
- `src/renderer/domain/chat/identityEvents.ts` (botInfo codec),
  `src/renderer/domain/chat/botInfo*.ts`, the room header in `Room.tsx` /
  `RoomHeader`, `src/renderer/domain/chain/*` (the `balanceOf` read).
- `docs/review/M12e.md` answers 4–6.

## Steps (desktop)

1. **Wait for `docs/spec/vectors-0008c.md`** from the pca agent (poll the
   file; it lands within minutes). Decode `pending` (optional; absent = 0);
   an older v2 `botInfo` still decodes. Encode too (the desktop's own future
   bots). Pin the vector bytes in `content.spec.ts`.
2. **Header**: show `balance − pending` as the number ("0.7 PAS (~7
   replies)"); never a second number in the label. Tooltip on the number:
   "1 PAS on chain · 0.3 not yet charged" when pending > 0. Re-read the
   chain when a `transactionReference` from the bot arrives (a charge) and
   on each new block as before; reset the pending view when a newer
   `botInfo` arrives.
3. **Archived chats unarchive on a new message unless muted** (Telegram).
4. **Pinned chats sit above the Assistant and the Faucet.**
5. **Forward offers the Assistant as a target** ("Ask the Assistant").
6. **e2e**: `npm run e2e:meter` extended: after two metered replies the
   header value (read through the domain, as the header does) equals the
   bot's `/balance` number (`HEADER_MATCHES_BALANCE`).
7. **Run**: `npm run check`, `npm run smoke` (headless flags!),
   `npm run e2e:meter`, `npm run screenshots -- --only room-meter` (add the
   shot if missing: the header with the tooltip open).
