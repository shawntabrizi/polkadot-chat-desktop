# M19 — First shareable release: v0.2.0-preview

## Goal

A build the owner can hand to testers: the profile migration code removed
(the owner's data is migrated; the app only knows the profiles layout), a
"Show recovery phrase" item, a tester README with install steps for an
unsigned macOS app, version 0.2.0, a changelog from the milestone reviews,
and a GitHub Release with the dmg attached (the repo becomes public; the
owner has no Apple Developer ID, so no signing or notarization).

## Read first

- `src/main/profiles*.ts` and `docs/decisions.md` "## M18" (the migration
  code and its tests), `src/main/identity/store.ts` (where the mnemonic is
  sealed with safeStorage), `src/renderer/ui/Settings.tsx`, `README.md`,
  `package.json` (version), `electron-builder.yml`, `docs/review/M*.md`
  (the changelog sources), `AGENTS.md`.

## Steps

1. **Remove the migration.** Delete the old-layout → `profiles/default`
   migration and its tests and the `PROFILE_MIGRATED` / `MIGRATE_OK` smoke
   lines; a data folder without `profiles.json` is simply a fresh install.
   Keep the idempotent "ensure default profile" path.
2. **Show recovery phrase.** Settings › Security: "Show recovery phrase"
   reveals the 12 words after the person types the word `reveal` in a field
   (no modal; an inline panel), with a warning line that whoever holds the
   phrase holds the identity, a Copy button, and auto-hide after 60 s.
   Also "Add profile from a recovery phrase" in the profile picker
   (restore: derives the identity, reads its username from the People chain,
   creates the profile). Tests: the phrase is never logged or written
   unsealed; restore yields the same account id.
3. **Tester README.** `README.md` gets a "Try it (macOS, Apple Silicon)"
   section: download the dmg from Releases; because the app is not signed,
   macOS refuses the first open: Control-click the app in Applications →
   Open → Open, or `xattr -dr com.apple.quarantine "/Applications/Polkadot
   Chat.app"`; devnet only, test funds have no value; the demo bots; where
   the data lives; how to report an issue; that the recovery phrase is the
   only backup. Keep it short and plain.
4. **Version and changelog.** `package.json` version 0.2.0; `CHANGELOG.md`
   with a 0.2.0-preview section written from `docs/review/M7…M18.md`: one
   line per user-visible feature, grouped (chat, money, agents and bots,
   groups, attachments, contracts), plus "known limits" (devnet only,
   unsigned build, 50-statement allowance per identity, Polkadot.js Apps
   cannot decode this runtime).
5. **Release script.** `scripts/release.sh <tag>`: checks the tree is clean
   and the tag matches `package.json`, runs `npm run check`, `npm run
   package`, `npm run smoke:packaged`, then `gh release create <tag>
   --prerelease --title "Polkadot Chat <tag>" --notes-file
   <changelog section> "dist/Polkadot Chat-<version>-arm64.dmg"`. Do NOT run
   the `gh release create` step yourself: stop before it and print the exact
   command; the coordinator runs it after the owner makes the repo public.
6. **Run**: `npm run check`, `npm run smoke`, `npm run package`,
   `npm run smoke:packaged`, `npm run e2e:profiles`.

## Do not

- No modal. No new dependency. Never print or log the phrase.
- Never touch the owner's real data folder. Do not run `gh release`.
- Do not edit `docs/spec/*.md` or `docs/milestones/*.md`.
