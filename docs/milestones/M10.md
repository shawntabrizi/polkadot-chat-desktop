# M10 — Bot info, Faucet chat, and the composer command menu

## Goal

Bots identify themselves (spec 0008): a badge, a description, a greeting, and a
command menu in the composer. A built-in **Faucet** chat gives test funds for
devnet. The `pca` half (another agent, same branch): send `botInfo` on accept
and on `/start`, from the persona/config. This milestone needs no contract
decision; contract calls are M11.

## Read first

- `docs/spec/0008-bot-info.md` (authoritative), `docs/spec/0007-transactions.md`
  (outline only, nothing to build), `docs/spec/README.md`, `docs/spec/kinds.md`,
  `docs/spec/vectors-0006.md` (vector file pattern; expect `vectors-0008.md`).
- `src/renderer/domain/chat/identityEvents.ts`, `content.ts`, `messages.ts`,

- `.refs/polkadot-design-system/SKILL.md` §8 (icons), §10 (badges are
  `rounded-full`, not pills), §11 (copy).

## Steps

1. **Codec.** Kind 244 `botInfo` per the spec; poll for
   `docs/spec/vectors-0008.md` from the pca agent (60 s, up to 25 min); decode
   byte for byte; derive and write it if absent.
2. **Store and render.** Per-peer `botInfo` in Dexie (`peerInfo` table, latest
   version wins). Badge: a small `Bot` (kind 0) or `Sparkles` (kind 1) Lucide
   icon after the name in the chat row and the room header, `text-fg-secondary`,
   with a tooltip "Bot" / "AI agent". Header subtitle: the description
   (truncated). Greeting: a system-style row when the info first arrives.
   Never a bubble. Add a spec.
3. **Command menu.** Typing `/` at the start of the composer opens a popover
   listing the peer's commands (`/name — description`), filtered as you type,
   ↑/↓ + Enter/Tab to pick, Esc closes; picking inserts `/name `. Bots without
   `botInfo` get no menu. The Assistant gets a fixed local list (`/reset`,
   `/model`). Spec for the filter and selection.
4. **`/start`.** When a room with a bot opens for the first time after accept
   and no `botInfo` is stored yet, send `/start` once automatically (a plain
   text message), so older bots answer with their help text and new bots with
   `botInfo`. Record in decisions.
5. **Search.** A "Bots" section in search results (after Chats and contacts,
   before Global): peers with `botInfo`, name and description.
6. **Faucet chat.** A built-in local contact "Faucet" (`local:faucet`, badge
   kind 0, description "Test funds for devnet"), first row after the
   Assistant, with a greeting and one keyboard: "Get test funds" as a `url`
   button opening the public Paseo faucet with the user's address prefilled
   (`https://faucet.polkadot.io/?parachain=1000&address=<ss58>`; verify the
   query parameters against the faucet page and record what works), plus
   "Copy my address" as a `command` handled locally (copies the SS58 to the
   clipboard and confirms with a system row). Everything local, nothing on
   the wire. Spec for the keyboard content.
7. **e2e.** `scripts/e2e-botinfo.mjs` → `"e2e:botinfo"`: request/accept
   with `pcdguide.70`, expect `botInfo` within 30 s (print `BOTINFO_RECEIVED
   name=… commands=<n>`), send `/start`, expect it again or a greeting text
   (print `START_OK`), then `BOTINFO_OK`; exit 9 on timeout.
8. **Screenshots.** `room-bot.png` (badge, subtitle, greeting row, command
   popover open), `faucet.png`, and `search-bots.png` in both themes.
9. **Run**: `npm run check`, `npm run smoke`, `npm run e2e:botinfo`,
   `npm run screenshots`.
