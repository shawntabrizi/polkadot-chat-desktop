# M0 — Electron shell around the web client

## Goal

An Electron app that opens one window showing the existing `polkadot-chat-web`
React client unchanged. `npm run check` is green. `npm run smoke` starts the app
headlessly-enough, loads the renderer, prints `SMOKE_OK`, and exits 0.

## Read first

- `PLAN.md` (whole file) and `AGENTS.md`.
- `.refs/polkadot-chat-web/package.json`, `vite.config.ts`, `tsconfig.json`,
  `eslint.config.js`, `vitest.setup.ts`, `index.html`, `src/main.tsx`.
- `.refs/polkadot-chat-web/AGENTS.md` and `docs/decisions.md` (dependency pins).
- `.refs/polkadot-desktop/package.json` (only to see the Electron version).

## Steps

1. **Find versions.** Run `npm view electron-vite version` and
   `npm view electron-vite peerDependencies`. Pick the newest `electron-vite`
   older than three days. Pick the newest `vite` that satisfies its peer range
   and is older than three days. Write both to `docs/decisions.md`.

2. **package.json.** Create it with:
   - `"name": "polkadot-chat-desktop"`, `"version": "0.1.0"`, `"private": true`,
     `"type": "module"`, `"main": "out/main/index.js"`.
   - `scripts`:
     - `"dev": "electron-vite dev"`
     - `"build": "electron-vite build"`
     - `"check": "tsc --noEmit -p tsconfig.json && vitest run && eslint ."`
     - `"test": "vitest run"`
     - `"lint": "eslint ."`
     - `"smoke": "npm run build && electron out/main/index.js --smoke"`
   - `dependencies`: copy every entry of
     `.refs/polkadot-chat-web/package.json` `dependencies` with the same pinned
     versions. Do not add others in M0.
   - `devDependencies`: copy every entry of the web client's `devDependencies`
     with the same versions, then add `electron` `44.4.1`, `electron-vite`
     (version from step 1), and set `vite` to the version from step 1. Add
     `@types/node` at the newest version older than three days.
   Run `npm install`. If a pin is refused, apply the rule in `PLAN.md` "Stack".

3. **Copy the renderer.** Copy `.refs/polkadot-chat-web/src` to
   `src/renderer` (all files, including `*.spec.ts`), and
   `.refs/polkadot-chat-web/index.html` to `src/renderer/index.html`. In the
   copied `index.html` point the script tag at `./main.tsx`. Add this header to
   `src/renderer/README.md`: "Copied from .refs/polkadot-chat-web/src on
   2026-09-23. Keep in sync by hand; see docs/decisions.md." Do not change the
   copied code in M0 except import paths that break.

4. **Main process.** Create `src/main/index.ts`:
   - Import `app`, `BrowserWindow` from `electron`.
   - On `app.whenReady()`, create a `BrowserWindow` 1200x800 with
     `webPreferences: { preload: <path to out/preload/index.js>, contextIsolation: true, nodeIntegration: false, sandbox: true }`.
   - In dev (`process.env.ELECTRON_RENDERER_URL` set) call
     `win.loadURL(process.env.ELECTRON_RENDERER_URL)`; otherwise
     `win.loadFile(<out/renderer/index.html>)`.
   - If `process.argv.includes('--smoke')`: do not show the window
     (`show: false`), wait for `win.webContents.once('did-finish-load')`, then
     `console.log('SMOKE_OK')` and `app.exit(0)`. If loading fails
     (`did-fail-load`) print `SMOKE_FAIL <errorDescription>` and `app.exit(1)`.
     Also add a 30 s timer that prints `SMOKE_TIMEOUT` and exits 2.
   - On `window-all-closed` quit unless `process.platform === 'darwin'`.

5. **Preload.** Create `src/preload/index.ts` that uses `contextBridge.exposeInMainWorld('desktop', { version: process.versions.electron })`.
   Create `src/shared/desktop-api.ts` with
   `export type DesktopApi = { version: string }` and a global declaration
   `interface Window { desktop: DesktopApi }`. The renderer must compile with
   and without `window.desktop` (it is absent in vitest).

6. **electron-vite config.** Create `electron.vite.config.ts` with three
   sections: `main` (entry `src/main/index.ts`), `preload` (entry
   `src/preload/index.ts`), `renderer` (root `src/renderer`, entry
   `src/renderer/index.html`, plugin `@vitejs/plugin-react`). Output goes to
   `out/`.

7. **tsconfig.** One `tsconfig.json` that covers `src/**/*`,
   `electron.vite.config.ts` and `vitest.setup.ts` with `strict: true`,
   `moduleResolution: "bundler"`, `jsx: "react-jsx"`, `types: ["node", "vite/client"]`,
   `noEmit: true`. If `src/renderer` needs DOM libs and `src/main` needs node
   types at the same time, keep one config with both `lib: ["ES2023", "DOM", "DOM.Iterable"]` and `types` as above; record the choice.

8. **eslint.** Copy the web client's `eslint.config.js`. Add one rule for files
   under `src/renderer/**`: `no-restricted-imports` with patterns `electron`,
   `node:*`, `fs`, `path`, `child_process` (message: "renderer must build for
   the browser"). Ignore `out/` and `dist/`.

9. **vitest.** Copy `vitest.setup.ts` from the web client. Configure vitest
   (in `electron.vite.config.ts` `renderer.test` or a `vitest.config.ts`) so
   `vitest run` finds `src/renderer/**/*.spec.ts` with `environment: 'jsdom'` if
   the web client used it, otherwise the same environment it used.

10. **Run.** `npm run check` must be green. `npm run smoke` must print
    `SMOKE_OK` and exit 0. If the renderer fails to load because of a path,
    fix the path; do not remove renderer code.

11. **README.md** at the repo root: name, one paragraph, the four npm scripts,
    and "Reference code: `.refs/` (git-ignored symlinks; see PLAN.md)".

## Do not

- Do not modify `.refs/`.
- Do not add UI, IPC channels, or identity code. That is M1.
- Do not add Tailwind, routers, state libraries.
- Do not use `electron-builder` yet (M3).

## Acceptance

```sh
npm run check          # exit 0
npm run smoke          # prints SMOKE_OK, exit 0
git status --short     # empty after commit
```
